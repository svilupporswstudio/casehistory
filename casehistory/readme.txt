== Installation ==

= ENG =
1. Install and activate the required plugin "Meta Box" via WordPress Plugins
2. Upload 'casehistory' directory to the '/wp-content/plugins/' directory
3. Activate the plugin through the 'Plugins' menu in WordPress

= ITA =
1. Installa e attiva il plugin richiesto "Meta Box" dalla sezione Plugin di WordPress
2. Carica la cartella 'casehistory' via ftp su '/wp-content/plugins/'
3. Attiva il plugin attraverso la sezione 'Plugins' dentro all'area riservata WordPress
